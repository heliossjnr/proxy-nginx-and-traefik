Resumo das alterações no projeto proxy-nginx-and-traefik:

[NGINX] Proxy Reverso com NGINX (abordagem estática)
  - nginx/nginx-proxy: Proxy central com nginx.conf, roteando por server_name
    (projeto1.empresa, projeto2.empresa, projeto3.empresa)
  - nginx/projeto1, projeto2, projeto3: Serviços backend com NGINX Alpine,
    cada um com docker-compose.yml, nginx.conf e html/index.html
  - Rede Docker compartilhada: web-network (bridge)
  - DNS interno via resolver 127.0.0.11

[TRAEFIK] Proxy Reverso com Traefik v3 (abordagem dinâmica)
  - traefik/traefik-proxy: Proxy central com docker-compose.yml e traefik.yml
    Dashboard exposto na porta 8080
  - traefik/projeto1, projeto2, projeto3: Serviços backend gerenciados por
    labels Docker (traefik.enable=true, regra Host, porta interna)
  - Descoberta automática de containers via Docker socket
  - EntryPoints configurados: web (:80) e websecure (:443)

[MONITORAMENTO] Stack de observabilidade (toda via Traefik)
  - monitoring/docker-compose.yml:
    - cAdvisor: Métricas de containers (CPU, memória, rede, disco)
    - Node Exporter: Métricas do host/servidor
    - Grafana: Dashboards e visualização (admin/admin)
    - Dockhand: Gerenciador visual de containers Docker
  - Todos os serviços usam labels Traefik para roteamento por domínio
    (ex: grafana.empresa, cadvisor.empresa, dockhand.empresa)

[TESTES] Ferramenta de benchmark HTTP
  - hey/testes.bat: Script para teste de carga com hey
